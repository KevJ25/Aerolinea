Aviso de privacidad

Este sistema es un proyecto académico. Use únicamente datos ficticios: no capture datos personales reales.

Datos que se recaban

Nombre, correo electrónico y contraseña. La contraseña se almacena únicamente como un resumen criptográfico; nadie, incluido el equipo del proyecto, puede conocerla.

Finalidad

Identificar a cada usuario, permitirle gestionar sus reservaciones y registrar las operaciones que realiza, como exige el control de calidad del proyecto.

Conservación y acceso

Los datos se conservan mientras dure el proyecto. Solo los administradores del sistema pueden consultarlos. Los registros de operaciones no contienen contraseñas.

Texto de referencia elaborado bajo el principio de minimización de la LFPDPPP para fines académicos; no sustituye un aviso de privacidad para un sistema en producción.
